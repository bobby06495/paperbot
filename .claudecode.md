# Custom Workflows

## Code Review Execution Loop
Whenever the user asks you to "process the code review" or mentions `review_comments.md`, you must strictly follow these sequential steps:
1. Read the local `review_comments.md` file completely.
2. Analyze all the actionable feedback and constraints contained inside it.
3. Present a clear, bulleted summary to the user outlining the exact changes you intend to make based on this review.
4. **STOP and explicitly seek the user's approval** before making any modifications to the codebase. Do not proceed until they give consent.
5. Once approved, implement the fixes while strictly keeping the core project logic, business requirements, and original architecture intact.
